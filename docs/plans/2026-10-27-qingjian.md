# 青简 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `com.oyp.pytx` 重做成 Material 3 的「青简」书刊阅读器，只复用歌德借阅机后端接口。

**Architecture:** iApp 工程 `com.qingjian.reader`；`.iyu` 声明页面布局，`.mjava` 承担网络、数据、样式与列表渲染。列表用 ScrollView + 动态 addView，封面图走 iApp 自带 `i.us(view,"src",url)`；阅读器用 WebView 渲染单页 HTML，外层 chrome 自制。模块按职责拆：`qj_core`（接口）、`qj_store`（历史与缓存）、`qj_ui`（色板/图标/底栏）、`qj_list`（列表项）、`qj_reader`（阅读）、`qj_pages`（首页/详情/搜索控制器）。

**Tech Stack:** iApp 5.0.1013（裕 3 + mjava/BeanShell）、Android API 34、material 1.13.0、org.json、WebView。

**Spec:** `docs/specs/2026-10-27-qingjian-design.md`

## Global Constraints

- 包名 `com.qingjian.reader`；App 名「青简」；不得出现任何个人姓名、缩写、个人域名
- iApp 5.0.1013 / API 34；组件一律优先 `com.google.android.material.*` 全类名，并在 `build.xml` 的 `<newControl>` 登记
- `.iyu` 事件体只允许 `call` / `addv`；其余逻辑全部下沉 mjava
- 色板（浅色）：surface `#FBF8F1`、surfaceContainer `#F5F2EA`、onSurface `#1B1C18`、onSurfaceVariant `#414944`、
  primary `#3F6459`、onPrimary `#FFFFFF`、primaryContainer `#C3E9DC`、tertiary `#79582B`、outline `#717973`
- 色板（深色）：surface `#121511`、surfaceContainer `#1E211D`、onSurface `#E3E3DA`、onSurfaceVariant `#C0C9C1`、
  primary `#A9CDC1`、onPrimary `#12332C`、primaryContainer `#2A4A42`、tertiary `#E4C28C`、outline `#8A938C`
- 字号只四级：32 展示 / 20 标题 / 16 正文 / 13 辅助；阅读正文 18sp，用户可调 16 / 18 / 21
- 间距取 4 的倍数，常用 8/12/16/24/32；页边距列表 16dp、详情与阅读 24dp；可点元素触控 ≥44×44dp
- 深色模式跟随系统，不做 App 内开关
- 离线只保留「上一次成功缓存」，不内置示例书库
- 后端 `gedeid=84751638`；图书分类 123 无数据不用；期刊搜索只能本地过滤
- 阅读接口必须走 `/o/a.h?a=GEDE:<surl>` 取 token → `readNew.jspx`；旧 `epub_epubRead_read.jspx` 对期刊 500

## Review Focus

- 接口返回 `result:0` / 空列表 / 超时：页面必须显示空态或失败态，不能白屏或崩
- `surl` 缺失或 `/o/a.h` 页面结构变化：阅读器给可读失败提示，正文区不显示假内容
- 大分类（843 条）分页：连续「加载更多」不重复、不跳号；到最后一页按钮消失
- 标题/简介含引号、竖线、换行：足迹 JSONL 与阅读缓存不被写坏
- 系统深色模式在阅读中切换：页面重建后回到原页码，正文配色跟随
- 缺一个 Material 方法会中断整个 `loading`：每页初始化按区块隔离，可疑调用放最后

### Task 3: qj_core 数据层

**Files:**
- Create: `src/qj_core.mjava`
- Create: `src/qj_store.mjava`

**Interfaces:**
- Consumes: Task 2 验证过的 `i.hs` / 线程 / JSON 写法
- Produces:
  - `ArrayList qj_core.books(int cataid, int page, int size)`，item 键：`key,type,title,author,summary,cover,surl,bookNum,newbook`
  - `ArrayList qj_core.searchBooks(String kw, int page, int size)`
  - `ArrayList qj_core.magazines(int cataid, int page, int size)`，item 键：`key,type,title,author,summary,cover,surl,magazineId`
  - `ArrayList qj_core.issues(int magazineId)`，item 键：`key,type,title,issueLabel,cover,surl,magazineId,issueNum`
  - `JSONObject qj_core.read(String surl, int fsize)` → `contents(JSONArray) / catalogs(JSONArray) / pageAll(int)`
  - `void qj_store.saveHistory(String itemJson, int page)`、`ArrayList qj_store.history()`、`void qj_store.clearHistory()`
  - `void qj_store.cache(String key, String json)`、`String qj_store.cacheGet(String key)`

- [ ] **Step 1: 实现列表/搜索/期次**

统一 `get(url)` 包装 `i.hs` + `result==1` 判定；`type` 由调用方给（图书 `ebook`、期刊 `magazine`）。
图书 `cover` 取 `cover`，期刊 `cover` 取 `coverPath`；`surl` 原样存（可能无协议头，使用处统一补 `https://`）。

- [ ] **Step 2: 实现阅读 token 与正文**

`token(surl)`：GET `https://gede.5read.com/o/a.h?a=GEDE:<URLEncoder.encode(surl,"UTF-8")>`，
正则取 `detailUrl:\s*'([^']+)'` 与 `from:\s*'([^']*)'`、`sid:\s*'([^']*)'`。
`read()`：拼 `readNew.jspx?psize=10000&sid=&ucatalog=true&ctype=3&fsize=&from=&detailUrl=`，返回 `msg`。

- [ ] **Step 3: 实现历史与缓存**

历史文件 `qj_store.dir() = activity.getFilesDir()+"/qingjian/"`（必须带子目录，开发模式 `getFilesDir` 多工程共用）；
`history.jsonl` 一行一个对象，按 `key` 去重就地更新，最多 50 条；缓存 `cache/<key>.json`。
写入用 `JSONObject.quote` 级别的转义，保证含 `"`、`|`、换行的标题不会破坏行结构；
自检：写一条标题为 `测试"引号|竖线` 的记录，重新读出后字段与原文一致（日志 `QJ store esc=ok`）。

- [ ] **Step 4: 自检并验收**

临时在首页 `loading` 调 `qj_core.books(124,1,10)` 与 `qj_core.magazines(6,1,5)`，日志 `QJ core books=10 mags=5`。
投递运行，日志符合即通过；随后删掉临时调用。
